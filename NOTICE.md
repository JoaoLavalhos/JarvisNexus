# Attribution and project origin

JarvisNexus is developed and maintained by **João Lavalhos**.

The project began as an experimental evolution of the open-source project
[Mark-LVI](https://github.com/FatihMakes/Mark-LVI) by **FatihMakes**. Parts of the
current codebase are still derived from that project and remain subject to its
original **CC BY-NC 4.0** license and attribution requirements.

JarvisNexus adds and is progressively moving toward its own architecture,
including its Nexus agent layer, Groq-based speech recognition path, OpenCode / OpenAI
agent integration, execution monitoring, permissions, diagnostics, logging, screen
capture workflows and the new IGNIS visual core system.

As inherited components are replaced, this notice will continue to document the
project's technical origin and the attribution required by any remaining derived code.
